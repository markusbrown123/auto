# auto

Holds the shared website design skills in `.claude/skills/` (Taste Skill, Web Design Guidelines, Awesome Design, Image-to-Code, Playwright CLI, and the `website-standards` workflow that ties them together). The same folder lives in automaton-, narrativa-site, and premium-client-redesigns.

To bring the standards to a new site repo, copy `.claude/skills/` into it and add the "Website design standards" note from `CLAUDE.md`. Sources, licenses, and update steps are in `.claude/skills/README.md`.
