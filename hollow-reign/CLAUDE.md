## Tools
- Godot binary: `.tools/Godot_v4.6-stable_linux.x86_64` (not committed).
- `tools/check.sh` script errors · `tools/test.sh` all suites · `tools/shoot.sh <out> <times> [args]` screenshots (xvfb + lavapipe, `VK_ICD_FILENAMES=/opt/lavapipe/lvp_icd.json`).
- Dev args after `--`: `--demo=<foe> --bot=3 --skip_intro`, `--screen=title|sanctuary|training|explore|weapons|animtest|cine|cinewalk`, `--body=m|f`, `--model=<glb name>`.
- Generation: `tools/concepts.py`, `tools/tripo.py`, `tools/voices.py`, `tools/music.py` (Higgsfield CLI needs `stdin=DEVNULL`; run speech jobs one at a time). `tools/bake_anims.gd` bakes animation GLBs in `art/anim*/` to `assets/anim/humanoid.res`.
- `art/` has a `.gdignore`: load from it only with `GLTFDocument`, never `load()`.
- GDScript traps: do not name functions `_set` or `_input`; type loop variables; removing files by glob is blocked — remove named files.
