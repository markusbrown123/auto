# Recorded audio sources (audition candidates)

Ledger of every recorded source file behind `art/sfx_recorded/` and `marketing/audio_pass/audition/`. Written 2026-11-28.

**Status: audition only.** Nothing here is in `assets/` or wired to game code. Nobody has listened to any of it; the owner decides by ear. Every file below is a real recording found on OpenGameArt.org or Freesound.org under CC0 or CC BY 4.0. No file came from a game, a commercial pack, a "royalty-free, no redistribution" library, or a NonCommercial / NoDerivatives / Sampling+ licence; those were skipped when seen.

## How to read this
- One row per **source file**. "Our files" are the cleaned single shots in `art/sfx_recorded/<category>/` (WAV, 44.1 kHz; one-shots 24-bit mono, 30 s loops 16-bit stereo).
- **Freesound rows used the preview, not the original.** Original downloads need a Freesound OAuth2 login, which this machine does not have; the API key only allows search and the `preview-hq-ogg` / `preview-hq-mp3` files (lossy, about 100 to 190 kbps). If a candidate is approved, download the original WAV/FLAC from the same page (free Freesound account) and re-cut it with the same settings before it goes anywhere near `assets/`.
- OpenGameArt rows used the lossless file inside the pack. Licences were read on each item's page (and in the archive's readme where there is one); the page URL is given.
- Common processing (unless the row says otherwise): decoded with ffmpeg and resampled to 44.1 kHz; cut at the onset (4 ms pre-roll) to the next event or a maximum length; 30 Hz high-pass (60 Hz for whooshes and armour, 25 Hz for loops); 2 ms fade-in and a short fade-out; one-shots peak-normalised to -3 dBFS. Loops: 32 s excerpt, last 2 s equal-power cross-faded into the first 2 s, giving a 30 s loop. Audition files get one more gain step (see the audition README); the loop WAVs carry the same gain as their audition.
- Measurements of the source are of the file as downloaded (preview or original), downmixed to mono: peak (sample, dBFS) and the 10th percentile of 50 ms RMS ("floor10"), a rough noise-floor indicator for files with gaps between events. For continuous ambiences floor10 is just the quiet end of the sound, not noise.
