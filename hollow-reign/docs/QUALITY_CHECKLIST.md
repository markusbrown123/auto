# Quality checklist

An encounter is accepted only when every line is checked from captures, not from tests alone.
State: [ ] not yet · [~] partly · [x] verified (name the capture).

## Per encounter
- [ ] Sword grip in the palm, blade up; shield on the forearm (front, side, back views)
- [ ] All eight cuts travel the swiped direction
- [ ] Hits land on the body; parried blades touch; blocked blows land on the shield; dodged blows pass through empty space
- [ ] Feet do not slide in walk, footwork, dodge
- [ ] No weapon through own body in any state (idle, open, windup, recover, death)
- [ ] Transitions: no pops between states at 0.25× speed
- [ ] Boss has its own attack patterns and movement style
- [ ] Male and female knight both checked
- [ ] Each weapon class checked (sword, greatsword, axe, dual)
- [ ] Camera keeps both fighters readable through dodges and pushback
- [ ] Sounds fire on the visible frame of contact
- [ ] Triangle count and draw calls recorded
